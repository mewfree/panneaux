#+title: Scraper RSR
#+language: fr

Crawler Playwright pour le
[[https://www.rsr.transports.gouv.qc.ca/Dispositifs/Panneaux.aspx][Répertoire des dispositifs de signalisation routière]].

* Usage

Depuis la racine du monorepo :

#+begin_src bash
pnpm install
pnpm --filter @panneaux/scraper exec playwright install chromium

# Échantillon (quelques catégories)
pnpm scrape:sample

# Si Cloudflare bloque (403) :
pnpm --filter @panneaux/scraper scrape -- --sample --headed

# Scrape complet
pnpm scrape
#+end_src

** Options

| Flag              | Description                    |
|-------------------+--------------------------------|
| ~--sample~        | Limite catégories + items      |
| ~--headed~        | Navigateur visible (défis CF)  |
| ~--skip-details~  | Liste seulement                |
| ~--skip-images~   | Pas de téléchargement d’images |
| ~--delay 750~     | Délai entre navigations (ms)   |

* Images Open Graph (partage social)

Cartes 1200×630 avec le panneau + code + nom :

#+begin_src bash
pnpm og:generate
# puis upload R2 (clés og/{cid}) :
for f in data/og/*; do
  key="og/$(basename "${f%.*}")"
  npx wrangler r2 object put "panneaux-images/${key}" --file="$f" --remote
done
#+end_src

Servies par le Worker sur ~/og/{cid}.png~. Les crawlers (Facebook, Slack…)
reçoivent aussi des meta OG statiques sur ~/panneau/...~.

* Rebuild depuis le cache HTML

Si les pages détail sont déjà dans ~scraper/.cache/html/~ :

#+begin_src bash
pnpm scrape:rebuild
#+end_src

Réécrit ~data/panneaux.json~ avec les bons sélecteurs (code, nom, description,
usage, couleur, pellicule, Tome V) sans recontacter le RSR.

* Sorties

- ~data/panneaux.json~ — catalogue
- ~data/scrape-report.json~ — métriques / erreurs
- ~data/images/{cid}.png~ — images locales (gitignorées)
- ~scraper/.cache/html/~ — HTML brut pour debug

* Éthique

- Rate-limit respectueux
- User-Agent identifiable
- Usage de *référence / recherche* uniquement (pas d’entraînement IA)
- Toujours pointer vers le site officiel sur le frontend
